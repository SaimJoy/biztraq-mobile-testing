# BizTRAQ mobile test automation

Test automation for the BizTRAQ mobile app (`com.triulta.biztraq`).

This repository holds the Flutter test harness: Riverpod unit and widget tests, Patrol end-to-end tests, and a GitHub Actions workflow. The API host is `https://biztraqonline.com`.

Setup, devices, and how to run the tests are in [SETUP.md](SETUP.md).
